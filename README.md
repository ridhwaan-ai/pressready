# PressReady

Manuscript in, publish-ready book out. Give it Markdown chapters, metadata and a front-cover image. It returns:

1. Kindle EPUB 3 (cover embedded, TOC, front/back matter)
2. Print interior PDF at the requested trim size (5x8, 5.5x8.5, 6x9, 8.5x11)
3. Full-wrap paperback cover PDF (spine width computed from page count and paper type)
4. Upload checklist (JSON) with the values KDP asks for

Status: pre-release. Not deployed or published to PyPI yet. See ROADMAP.md.

## CLI

    pip install -e .
    pressready build manuscript/ --trim 5.5x8.5 --paper cream

## MCP server

    pressready-mcp

Tools: `build_book`, `spine_width`, `list_trim_sizes`.

## HTTP API

    uvicorn pressready.api:app

- `POST /v1/books` creates a job, `GET /v1/books/{id}` returns status and download URLs
- `GET /v1/limits`, `GET /v1/pricing`: machine-readable limits and pricing
- `GET /llms.txt`, `GET /quickstart.txt`: agent docs
- `GET /openapi.json`: OpenAPI spec
- `GET /health`: health check

Jobs are in memory and expire after about 15 minutes.

## Notes

PressReady produces files; it never logs in to KDP or any other site. Check the output in KDP's previewer before publishing. Output is generated by software; disclose AI use in KDP where its rules require it.
