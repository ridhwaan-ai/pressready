# Gumroad key product: Owner steps

Goal: sell a licence key that unlocks unlimited builds (sent as `Authorization: Bearer <key>`).
Code is already in `src/pressready/access.py`. Nothing here is automated; the Owner does it.

1. Sign in at gumroad.com (Owner's own account, payouts set up by the Owner).
2. Products > New product > type "Digital product" (or Membership if monthly access is wanted).
   - Name: `PressReady API key (unlimited builds)`
   - Price: pick one (suggested start: $9 one-off for 100 builds, or $9/month membership). Owner decides.
3. Product page > Content/Settings: tick **"Generate a unique license key per sale"**.
4. Description (honest, no fake claims):
   "Licence key for PressReady, an API/MCP/CLI that turns Markdown chapters + a cover image into a KDP-ready
   EPUB, print interior PDF and full-wrap cover PDF. Send the key as `Authorization: Bearer <key>`.
   Free tier: 3 builds/day without a key. Docs: https://pressready-wp38.onrender.com/llms.txt.
   Files are generated by software; you remain responsible for checking them before uploading to KDP."
5. Publish the product. Copy the product page URL (the buy URL).
6. Find the product id (Gumroad: Settings > Advanced shows it, or the "product_id" shown in the licence
   key API docs for your product). Send both values to the runtime.
7. On Render (or ask the runtime to set them): Environment variables
   - `PRESSREADY_GUMROAD_PRODUCT_ID` = product id
   - `PRESSREADY_BUY_URL` = buy URL
   Save; Render redeploys.
8. Test: buy your own key (or use a free $0 test sale), then call
   `GET /v1/pricing` and a build with the Bearer key.
